# Manual Frame Templates Folder

Place your transparent PNG frame templates in this folder (e.g., `my_custom_frame.png`).

You can load them directly in the app by typing the filename (including `.png`) into the "Load from templates/ Folder" section in the configuration panel.

## Frame Recommendation:
- Format: PNG with transparent windows.
- Size/Aspect Ratio: 4R standard (e.g. 1200x1800 for Portrait or 1800x1200 for Landscape).
